Inputmask + Vue: autocomplete / programmatic value update

Demonstrates that a value set programmatically (simulating browser autocomplete) correctly updates the bound Vue property via a triggered input event.

Vue property value: {{ phoneValue || '(empty)' }}

How it works: "Simulate autocomplete" sets the raw DOM value via the native setter (bypassing Inputmask's patched setter, the same way browsers do during autocomplete) and then dispatches a native input event. Inputmask processes the value and fires a second input event that Vue picks up, keeping the property in sync.
